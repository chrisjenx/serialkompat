# Security Policy

## Supported versions

serialkompat is pre-1.0. Until `1.0.0`, security fixes go into the latest release and `main` only.

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities.

Instead, report it privately through [GitHub Security Advisories](https://github.com/chrisjenx/serialkompat/security/advisories/new). That lets us discuss and fix the issue before it is disclosed.

We aim to acknowledge reports within a few days and will keep you updated until it is fixed. Thank you for helping keep serialkompat and its users safe.
